# Customer Segmentation & Market Demographics Dashboard

## Overview
This project analyzes customer demographics and market segmentation patterns using Python and Power BI.

## Technologies
- Python
- Pandas
- NumPy
- Power BI

## Features
- Data cleaning and preprocessing
- Customer segmentation analysis
- Demographic trend visualization
- Interactive dashboard

## Workflow
1. Clean raw data using Python.
2. Import processed data into Power BI.
3. Create interactive visualizations and reports.
4. Generate business insights.
